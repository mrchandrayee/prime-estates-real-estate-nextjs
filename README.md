A responsive **real estate marketing website** built with Next.js, TypeScript, and Tailwind CSS — featuring property listings, hero sections, and modern property showcase UI.

## ✨ Features

- 🏡 Real estate property showcase
- 🔍 Property listings with details
- 🎨 Modern marketing design
- 📱 Fully responsive layout
- ⚡ Next.js App Router
- 🎭 Smooth animations & transitions

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS

## 🚀 Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## 📁 Project Structure

